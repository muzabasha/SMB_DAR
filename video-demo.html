🎬 Video Setup Instructions

1. Prepare Your Video Files

Create MP4 and WebM versions of your video for maximum browser compatibility.

# Using FFmpeg to create MP4
ffmpeg -i input.mov -c:v libx264 -preset medium -crf 23 course-overview.mp4

# Using FFmpeg to create WebM
ffmpeg -i input.mov -c:v libvpx-vp9 -b:v 2M course-overview.webm

2. Add Files to Assets Folder

Place your video files in the assets directory:

assets/
├── course-overview.mp4
├── course-overview.webm
└── video-thumbnail.jpg

3. Update Video Configuration

Edit the courseVideo object in js/data.js with your video details:

courseVideo: {
  title: "Your Video Title",
  description: "Your video description",
  duration: "3:45",
  videoUrl: "assets/course-overview.mp4",
  videoWebM: "assets/course-overview.webm",
  poster: "assets/video-thumbnail.jpg"
}

4. Create Thumbnail Image

Generate a thumbnail from your video (1920x1080 recommended):

ffmpeg -i course-overview.mp4 -ss 00:00:05 -vframes 1 -vf scale=1920:1080 video-thumbnail.jpg

5. Test the Video

Open the main application and navigate to the Dashboard. The video should appear after the Welcome Card with full controls.

6. Deploy

Commit and push your video files to your repository:

git add assets/course-overview.mp4 assets/course-overview.webm assets/video-thumbnail.jpg
git commit -m "Add course overview video"
git push origin main
